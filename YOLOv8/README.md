# YOLOv8 학습 코드 및 데이터 전처리 코드


class_split : 클래스 별로 데이터를 나누기 위한 코드, 클래스 오라벨을 수동 검수하기 위함

cleanup_yolo_dataset : 라벨이 없는 데이터셋을 삭제하기 위한 코드, 필요없는 클래스 삭제 후 데이터 삭제를 위함

convert : 사진을 수중환경 처럼 보이도록 사진을 편집하는 코드, 직접 찍은 데이터 셋을 수중환경 처럼 보이게 하기 위함

count_original : 증강데이터와 오리지널 데이터의 갯수를 세는 코드, 공공데이터에서 증강데이터가 얼마나 있는 지 알아보기 위함

labels_modi : 라벨을 수정하는 코드, 공공데이터셋의 클래스를 프로젝트의 클래스 기준으로 변경하기 위함

rm_data : 증강 데이터 사이에서 오리지널 파일만 복사하는 코드, 증강데이터와 오리지널 데이터를 분리하기 위함

split_data : 하나의 데이터셋을 train, test, val로 나누는 코드

test_result : test 데이터셋을 모델에 넣어 모델의 성능을 확인하는 코드

test : 하나의 사진을 모델에 넣어 결과를 확인하는 코드
